# Пыльная дорога / Dust Road

Самостоятельный браузерный прототип автомобильного путешествия и выживания, вдохновлённый игровым циклом The Long Drive. Код, геометрия, интерфейс и звук созданы для этого проекта. Чужие модели, исходники, музыка и логотипы не используются.

## Запуск

Для локального запуска нужен Node.js 20 или новее и браузер с WebGL. Онлайн-версия открывается без установки на компьютере или смартфоне. В папке `dust-road`:

```sh
npm start
```

Откройте http://localhost:3000. Установка пакетов не нужна. Для проверок: `npm test`. Можно разместить папку на любом статическом HTTP-хостинге. Открытие `index.html` через `file://` не поддерживается из-за ES-модулей.

## Версия 0.2

3D-пустыня, извилистая дорога, детерминированная подгрузка окружения, управляемый автомобиль, сопротивление песка, торможение и задний ход. Есть внешний вид и камера из салона, пешее перемещение, расход топлива, повреждения от столкновений с камнями/кактусами/основным зданием станции, припасы на станциях каждые 350 м. Цель первой поездки: перевал на отметке 3 км; после него можно ехать дальше.

У станции выйдите из машины и подойдите к оранжевой канистре с маркером. Нажмите E: 12 л топлива и 35 единиц ремонта автоматически доставляются в машину. Одна станция выдаёт запас один раз за поездку. Бак вмещает 40 л.

| Клавиша | Действие |
| --- | --- |
| W / S или ↑ / ↓ | Газ / торможение и задний ход; пешком вперёд / назад |
| A / D или ← / → | Поворот руля; пешком поворот тела |
| Пробел | Тормоз |
| E | Выйти, сесть, забрать припасы |
| C | Внешняя камера / салон |
| Мышь | Обзор пешком и из салона после клика по сцене; также перетаскивание |
| Shift | Бег пешком |
| P | Сохранение |
| Esc | Пауза / продолжение |
| R | Эвакуация на дорогу: до 150 м назад, -1 л и -15 состояния, но минимум 3 л и 35 состояния |

Сохранения версионированы, проверяются при загрузке и остаются в localStorage этого браузера на этом адресе. Автосохранение каждые 12 игровых секунд, при паузе и уходе со страницы. На другом устройстве сохранений не будет. При очистке данных браузера они удаляются. Новая поездка заменяет существующее сохранение после подтверждения.

## Архитектура

`src/simulation.js`: состояние и правила, не зависит от DOM/WebGL. `src/renderer.js`: небольшой пакетный WebGL-рендерер. `src/world.js`: процедурная геометрия и машина. `src/main.js`: ввод, игровой цикл, камеры, интерфейс, звук и сохранения. `test/`: проверка игровой логики средствами Node.js. Внешних библиотек, CDN, аналитики и сетевых игровых сервисов нет.

Физика кинематическая, с фиксированными подшагами до 1/120 с. Это основа прототипа, не симуляция подвески, шин и трансмиссии. Низкое качество ограничивает разрешение и дальность окружения. Слабые устройства требуют проверки на реальном оборудовании.

## Ограничения

Нет разборки и крепления деталей, переносимого инвентаря, полноценной физики твёрдых тел, сохранения в облаке, мультиплеера, смены суток, озвученных персонажей. Коллизии упрощены; декоративные насосы, столбы, горы и навесы не имеют физического тела. Пешком есть столкновения с основным зданием, но не со всеми декорациями. Звук двигателя синтезирован. Камера салона упрощённая. Это игровой срез версии 0.2, не готовый коммерческий аналог.

План развития и критерии готовности: [ROADMAP.md](ROADMAP.md).

## Проверка версии 0.2

Автоматические тесты игровой логики и формирования геометрии выполняются командой `npm test`. Синтаксис модулей проверен Node.js. В облачном проверочном браузере WebGL недоступен; подтверждены загрузка страницы, стартовый интерфейс и сообщение об отсутствии WebGL. Визуальный рендер, ощущения от управления, звук и производительность на реальном GPU пока не проверены. Не считать прохождение модульных тестов полноценной игровой приёмкой.


## Смартфон

Управление появляется на сенсорных устройствах и экранах шириной до 900 px. Слева стрелки поворота, справа газ, задний ход и тормоз. Можно одновременно удерживать газ и поворот разными пальцами. Ведите пальцем по свободной части сцены для обзора. В пешем режиме газ становится кнопкой «Идти», стрелки поворачивают персонажа.

Кнопки «Выйти» / «За руль» / «Забрать» меняются по ситуации. «Камера» переключает салон и внешний вид. «Сохранить» сохраняет поездку, «На дорогу» вызывает эвакуацию со штрафом. Пауза доступна сверху. В альбомной ориентации виден более широкий участок дороги; портретная тоже поддерживается. Учтены вырезы экрана и нижний индикатор iPhone. На сенсорном устройстве автоматически выбирается низкое качество.

Раскладка проверена в браузерных областях 390×844, 844×390 и 320×568. 19 автоматических тестов прошли, включая одновременный газ/поворот и освобождение отдельных касаний. Полный игровой прогон на iPhone/Android и FPS пока не проверены, поскольку облачный браузер не предоставляет WebGL.

## Публикация

`npm run build` создаёт `dist/` только с HTML, CSS и игровыми модулями. Тесты, документация, Git и сервер разработки не попадают в опубликованную сборку. Конфигурация Sites хранится в `.openai/hosting.json`; исходники дополнительно сохраняются в ветке `feat/dust-road-prototype` репозитория `nsn99/chat-gpt`.

Адрес размещения: https://dust-road-nsn99.cmc501-7355.chatgpt.site


## Версия 0.3 · GitHub Pages

Основная публичная игра: https://nsn99.github.io/chat-gpt/ . Сборка находится в ветке gh-pages, исходники в feat/dust-road-prototype. Старый адрес Sites содержит предыдущую версию.

Новая поездка начинается внутри гаража с открытым выездом. Внешняя камера приближается в гараже, крыша вблизи скрыта для обзора. После прямого подъезда дорога чередует выраженные левые и правые зигзаги со сглаженными поворотами. Двенадцать машин движутся по трассе в обе стороны и переиспользуются за пределами видимого участка. Попутный трафик объезжает медленных участников, проверяя свободный встречный участок перед началом обгона. Это упрощённый ИИ, не полноценная модель дорожного движения; он не гарантирует предотвращение всех аварий. Столкновения повреждают машину игрока.

Мобильные приборы перенесены в узкую верхнюю строку; кнопки полупрозрачные и находятся по краям. Сохранение и эвакуация раскрываются кнопкой «Ещё». Для нового мира используется отдельный ключ сохранения dust-road-save-v2; старое сохранение не удаляется, но автоматически в новую трассу не переносится.

Проверка: 25 модульных тестов, включая старт/выезд из гаража, геометрию поворотов, встречный поток, условия обгона и столкновения. Полный 3D-прогон на реальном GPU остаётся необходимым.
